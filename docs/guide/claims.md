# 理赔实务

理赔是保险合同的履约环节，也是保险价值最直接的体现。

## 理赔流程

1. **出险报案**：通过客服电话、App、代理人报案（注意报案时效）
2. **提交材料**：索赔申请书、身份证明、保单、事故证明、损失清单等
3. **立案审核**：核实保险责任、事故真实性
4. **调查（必要时）**：现场查勘、走访、调阅病历/监控
5. **核定赔付**：计算赔款、出具理赔决定
6. **结案支付**：转账支付赔款

## 理赔时效（保险法规定）

- 情形复杂的，30 日内作出核定（合同另有约定除外）
- 属于保险责任的，达成协议后 10 日内赔付
- 不属于保险责任的，核定之日起 3 日内发出拒赔通知并说明理由
- 索赔时效：人寿保险 5 年，其他保险 2 年（自知道或应当知道保险事故发生之日起）

## 常见拒赔原因

1. 未如实告知（带病投保最常见）
2. 事故不属于保险责任范围
3. 等待期内出险
4. 属于免责条款情形（酒驾、无证驾驶、故意行为等）
5. 索赔超过时效
6. 未履行防止损失扩大等义务

## 争议解决途径

- 与保险公司协商
- 向保险公司总部或监管热线（12378）投诉
- 申请行业调解组织调解
- 仲裁（合同约定时）
- 诉讼

## 代位求偿

因第三者对保险标的造成损害而赔付的，保险人自赔付之日起在赔偿金额范围内代位行使被保险人对第三者请求赔偿的权利。被保险人不得擅自放弃对第三者的索赔权，否则保险人可不承担赔偿责任。
