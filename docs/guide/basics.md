# 保险的基本概念

## 什么是保险

保险是一种风险转移机制：投保人通过支付保费，将特定风险可能造成的经济损失转移给保险人（保险公司）。当合同约定的保险事故发生时，保险人按照约定承担赔偿或给付责任。

## 保险的四大基本原则

### 1. 最大诚信原则
- 投保方需如实告知（询问回答告知）
- 保险方需说明条款，尤其是免责条款
- 违反最大诚信可能导致合同解除、拒赔

### 2. 保险利益原则
- 投保人对保险标的必须具有法律上承认的利益
- 人身保险：投保时须具有保险利益
- 财产保险：事故发生时须具有保险利益

### 3. 损失补偿原则
- 补偿以实际损失为限，被保险人不能因保险获利
- 派生规则：代位求偿、重复保险分摊

### 4. 近因原则
- 造成损失的最直接、最有效、起主导作用的原因
- 近因属于保险责任的，保险人才承担赔付责任

## 保险的分类

| 维度 | 分类 |
| --- | --- |
| 按标的 | 人身保险 / 财产保险 |
| 按实施方式 | 自愿保险 / 强制保险（如交强险） |
| 按承保方式 | 原保险 / 再保险 |
| 按经营目的 | 商业保险 / 社会保险 |

## 相关概念速查

- **保险人**：保险公司，承担赔付责任的一方
- **投保人**：与保险人订立合同并支付保费的人
- **被保险人**：其财产或人身受合同保障的人
- **受益人**：人身保险中享有保险金请求权的人
- **保险金额**：保险人承担赔付责任的最高限额
- **保险价值**：保险标的的实际价值（财产险）
