# 保险合同要素

## 合同主体

- **当事人**：保险人、投保人
- **关系人**：被保险人、受益人
- **辅助人**：保险代理人、经纪人、公估人

## 保险合同的核心条款

1. **保险责任**：保险人承担的风险范围
2. **责任免除**：保险人不承担赔付的情形（免责条款需明确说明）
3. **保险期间**：合同的有效时间范围
4. **保险金额与保费**：赔付限额与对价
5. **如实告知与健康告知**：投保人的说明义务
6. **犹豫期、等待期、宽限期**：
   - 犹豫期（通常 10-20 天）：可无条件退保，仅扣除工本费
   - 等待期（健康险常见 30-180 天）：期内出险不赔
   - 宽限期（通常 60 天）：欠缴保费合同仍然有效

## 合同的订立、变更与终止

- **订立**：投保申请 → 核保 → 承保出单
- **变更**：主体变更、内容变更（需批改手续）
- **中止**：宽限期届满仍未缴费，合同效力中止（2 年内可复效）
- **终止**：期满、赔付完毕、解除（退保）

## 常见争议点

- 免责条款是否履行了明确说明义务
- 如实告知义务的范围界定
- 对格式条款有争议时，作有利于被保险人和受益人的解释（保险法第 30 条）
