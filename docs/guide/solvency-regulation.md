# 保险公司偿付能力与监管

偿付能力决定一家保险公司是否"赔得起"。对长期保单持有人（尤其是终身寿、年金险投保人），承保公司的偿付能力状况直接关乎几十年后保单能否兑现。本节解读偿二代监管体系和消费者如何判断保险公司安全性。

## 偿二代（C-ROSS）监管框架

2015 年偿二代一期落地，2022 Q1 偿二代二期实施，2025 年起全面到位。核心是**三支柱**体系：

| 支柱 | 内容 | 达标标准 |
| --- | --- | --- |
| 第一支柱（定量资本） | 核心偿付能力充足率 ≥ 50%<br>综合偿付能力充足率 ≥ 100% | 双指标必须同时满足 |
| 第二支柱（定性监管） | 风险综合评级 ≥ B 类 | A / B / C / D 四档，C、D 为不达标 |
| 第三支柱（市场约束） | 强制信息披露、外部审计、消费者知情权 | 定期公开偿付能力报告 |

### 三项核心指标解释

#### 1. 核心偿付能力充足率
- **公式**：核心资本 ÷ 最低资本 × 100%
- 核心资本 = 净资产 − 资本性负债（如次级债、分红型保险负债中属所有者权益部分调整项）
- 衡量保险公司**最高质量**资本的充足状况——越高越安全

#### 2. 综合偿付能力充足率
- **公式**：实际资本 ÷ 最低资本 × 100%
- 实际资本 = 核心资本 + 附属资本（如可转换债、次级定期债务等）
- 衡量资本总体充足状况；必须 ≥ 100%

#### 3. 风险综合评级
- 2025 年新版监管评级办法升级为 A / B / C / D 四档
- B 类及以上为达标；C 类和 D 类公司面临监管措施
- 评级依据：公司治理、偿付能力、负债质量、资产质量、风险管理、消费者权益保护等综合评估

## 偿二代二期的关键变化

相比一期，偿二代二期对更细颗粒度的风险计提资本：

| 变化 | 含义 |
| --- | --- |
| 资产端风险权重细化 | 不同信用等级、不同久期的资产（股票、债券、不动产）对应不同资本要求 |
| 负债端更保守 | 负债评估假设更审慎，隐性负债暴露更充分 |
| 资产负债匹配要求提升 | 久期错配（如用短期资产覆盖长期寿险负债）计提更多资本 |
| 利率风险单独计量 | 利率大幅波动时保险公司的重定价风险有独立资本覆盖 |

### 实际影响
- 偿二代二期要求更严，部分险企出现**监管评级下调**
- 2025 Q2 数据：14 家险企达 3A 评级，5 家为 C 级（不达标）
- 对消费者：偿二代二期整体降低了保险公司系统性风险，长期保单更安全

## 监管措施与退出机制

保险公司若不满足偿付能力监管要求，金融监管总局可采取的阶梯式措施：

1. **限制业务范围**：停止发展新业务
2. **责令增加资本金**：要求股东补充资本
3. **限制股东权利**：限制分红、转让股权等
4. **调整高管**：撤换董事、高管
5. **接管或重组**：极端情况下由监管接管

### 保险保障基金
保险公司被撤销或破产时，保险保障基金对保单持有人提供救济：
- 人寿保单 / 长期健康险保单：全额救济
- 财产险 / 短期健康险 / 意外险保单：最高救济 500 万 / 单
- 保险保障基金由所有保险公司共同出资，本质是行业担保机制

## 消费者如何判断保险公司安全性

### 三步法

#### Step 1：看偿付能力三项指标
- 访问 **国家金融监督管理总局官网** 或各保险公司年报 / 官网"信息披露"板块
- **要求**：核心偿付率 ≥ 80%、综合偿付率 ≥ 150%（比最低监管要求更严格的自我保护线）
- 低于此阈值的公司慎买新单

#### Step 2：看风险综合评级
- 金融监管总局每季度发布险企监管评级
- **优先 A 级**，B 级可接受，C / D 级谨慎

#### Step 3：看公司治理与品牌
- 股东背景（国资、头部外资、上市险企相对更稳）
- 长期经营历史（百年老店 / 成立 20 年以上）
- 投资策略是否激进（重仓权益类资产 + 高利率产品定价 = 利差损风险高）

### 实操建议

| 保单类型 | 最低安全门槛 | 原因 |
| --- | --- | --- |
| 一年期意外险、旅行险 | 综合偿付率 ≥ 100% 即可 | 保单期极短，敞口小 |
| 百万医疗险（一年期） | 同上 | 可随时停售换其他公司 |
| 重疾险（长期 / 终身） | 核心偿付率 ≥ 100%，评级 ≥ A | 保单期限长，承保公司要"活几十年" |
| 年金险 / 增额寿 | 同重疾险，**优先级最高** | 现金流要锁定 10—40 年 |

> 结论：**长期储蓄型保险（增额寿、年金险）对承保公司的安全性要求最高**，投保前务必查一下该公司最新偿付能力数据和风险评级。

## 评级机构的独立评级

监管之外，**标准普尔（S&P）、穆迪、惠誉** 等国际评级机构也为主要保险公司出具信用评级。AAA 为最高，A- 以上视为投资级。国内评级机构（中诚信、大公等）也有类似评级可供参考。
