# 核保流程

核保（Underwriting）是保险人评估风险并决定是否承保、以何种条件承保的过程。

## 核保的环节

1. **投保申请**：收集投保信息
2. **风险信息收集**：健康告知、财务告知、职业类别、既往理赔记录
3. **风险评估**：死亡率/发病率评估、道德风险与逆选择识别
4. **核保决定**：
   - 标准体承保
   - 加费承保
   - 除外责任承保
   - 延期
   - 拒保

## 人身险核保关注点

- **医学核保**：BMI、血压、血糖、既往病史、家族史
- **财务核保**：保额与收入匹配度，防范道德风险
- **职业核保**：高危职业加费或限额
- **常见体检阈值**：保额/年龄达到一定标准触发体检、生存调查

## 财险核保关注点

- 标的所处环境（地理位置、消防条件）
- 行业类型与历史赔付率
- 被保险人的风险管理水平
- 最大可能损失（PML）评估

## 智能核保趋势

- 规则引擎自动核保：告知事项 → 规则匹配 → 秒级结论
- 大数据风控：医保数据、健康行为数据辅助定价
- AI 影像识别：用于健康告知资料与体检报告的结构化解析
