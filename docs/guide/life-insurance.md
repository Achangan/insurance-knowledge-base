# 人寿保险

以被保险人的寿命为保险标的，以生存或死亡为给付条件的人身保险。

## 主要类型

### 定期寿险
- 保障固定期间（如 20 年、至 60 岁）
- 纯保障型，保费低、杠杆高
- 适合家庭经济支柱转移身故风险

### 终身寿险
- 保障终身，必然赔付
- 兼具保障与资产传承功能
- 增额终身寿险：保额按约定利率复利递增，侧重储蓄与传承

### 两全保险
- 生存至期满给付满期金，期内身故给付身故金
- "生死两全"，储蓄属性强，保费较高

### 年金保险
- 按约定周期（年/月）给付生存金
- 常用于养老规划、子女教育金
- 可附加万能账户实现二次增值

## 核心定价因素

- 死亡率（生命表）
- 预定利率
- 费用率

## 适用场景

| 需求 | 推荐类型 |
| --- | --- |
| 家庭责任期保障 | 定期寿险 |
| 财富传承 | 终身寿险 |
| 养老现金流 | 年金保险 |
