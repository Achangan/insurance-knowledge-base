# 财产保险

以财产及其有关利益为保险标的的保险，遵循损失补偿原则。

## 主要类型

### 企业财产保险
- 承保火灾、爆炸、自然灾害等造成的固定资产与存货损失
- 基本险 / 综合险 / 一切险，责任范围递增
- 可附加利润损失险（营业中断险）

### 家庭财产保险
- 保障房屋、装修、室内财产
- 常见附加：盗抢、水暖管爆裂、第三者责任

### 工程保险
- 建筑工程一切险、安装工程一切险
- 保障建设/安装期间的物质损失与第三者责任

### 责任保险
- 以被保险人的民事赔偿责任为标的
- 公众责任险、产品责任险、雇主责任险、职业责任险

### 信用与保证保险
- 信用保险：权利人投保，保障债务人违约风险
- 保证保险：债务人投保，为其履约能力提供担保

## 定值与不定值保险

- **定值保险**：事先约定保险价值，出险按约定价值赔付（如艺术品）
- **不定值保险**：出险时按实际损失核定，受足额/不足额投保影响

## 比例赔付公式

不足额投保时（保额 < 保险价值）：

```
赔款 = 实际损失 × (保险金额 ÷ 保险价值)
```
